# 更新履歴

## [0.02] - 2025.6.28

- パスと GUID の両方でエラーを確認し、互いの情報から修正できるようになりました。シーンが見つからなくなる問題を軽減しました。
- 起動と読み込みを高速化し、更新時に進捗バーを表示するようにしました。
- TagManagementWindow の UI レイアウトを改善しました。

## [0.03] - 2025.7.19

- スクリーンショットの日時で並べ替える機能を追加しました。

## [0.04] - 2025.8.23

- ダブルクリックでシーンを開けるようになりました。
- サムネイルを事前に選択しなくても、その上で右クリックメニューを開けるようになりました。
- Unity の Project ウィンドウと OS のファイルブラウザーで、ファイルの場所を表示する機能を追加しました。
- 撮影した画像がすぐに表示されない問題を修正しました。
- GUI の更新の遅れとエラーを修正しました。
- タグの背景色に合わせて、文字色を黒または白に自動で切り替えるようにしました。
- PNG/JPEG の切り替えと画質設定に対応し、保存時に同名の古い画像を削除するようにしました。
  - `Screenshot Settings...` ウィンドウを追加しました。
  - メニューを `Tools/CYN-lab/AvatarSceneBrowser/` に統一しました。
- イベントバスを導入し、ウィンドウ間の連携を改善しました。

## [0.1] - 2025.10

BOOTH で正式に公開しました。

## [0.11] - 2025.11.14

操作説明を追加しました。

## [0.2] - 2026.1

**1つのシーン内で複数の VRChat アバターを管理する機能**

- 同じシーン内のアバターごとに、スクリーンショットと設定を保存できるようになりました。
- 設定のサムネイルをダブルクリックするか、設定一覧の ▶ をクリックすると、アバターの表示・非表示を復元できます。
- ギャラリーで選択した画像には、Avatar 設定なら緑色、通常のシーン画像なら青色の枠を表示します。
- 右側の詳細パネルに、1体のアバターの設定か、複数のアバターの組み合わせかを表示します。
- Avatar 設定ごとにタグを付けられるようになりました。

## [0.21] - 2026.1.23

- Unity のバージョンによって UI の枠が真っ黒に表示される問題を修正しました。

## [0.22] - 2026.3.1

- シーン内のアバターが複数から1体になった際、古い複数アバターの画像に赤い警告アイコンを表示するようにしました。
- 現在開いているシーンで、画像が参照するアバターが削除されていた場合に、サムネイルに警告を表示するようにしました。
- シーンファイルの欠落と Avatar データの異常を分け、それぞれの件数をタイトルバーに表示するようにしました。

## [0.23] - 2026.3.20

- プラグイン名を `AvatarSceneBrowser` から `VRCAvatarSceneBrowser` に変更しました。
- メニューパスを `Tools/CYN-lab/VRCAvatarSceneBrowser/` に統一しました。
- 撮影ボタンからウィンドウを開いたときに、タイトルが `MainWindow` になる問題を修正しました。

## *ver0.3 2026.11.2*

**不具合修正**

- シーン名やアバター名が同じでも、別の設定のスクリーンショットを上書きしないようにしました。撮り直した場合も、既存の設定とタグは保持されます。
- Avatar 設定のスクリーンショットを保存できなかった場合は、元の画像とその関連付けを保持し、エラーを表示するようにしました。
- スクリーンショットや設定を1件削除しても、ほかの設定が共有している画像を誤って削除しないようにしました。削除に失敗した場合は、元のデータに戻します。
- シンボリックリンクを使うプロジェクトで、削除したはずの画像が残る問題を修正しました。
- シーンの切り替えをキャンセルした場合は、スクリーンショットの更新も中止するようにしました。
- タグ名を変更すると、関連する Avatar 設定内のタグ名も更新されるようにしました。タグの色はそのまま保持されます。
- タグの保存に失敗した場合は、元のデータに戻し、エラーを表示するようにしました。
- タグの使用回数に、Avatar 設定での使用も含めるようにしました。

**UI の改善**

- アバターの状態説明を見直し、複数のアバターがいるシーンで、1体だけを表示しているのか、複数を表示しているのかが分かりやすくなりました。通常のスクリーンショットでは、対応するシーンを開いてから「VRC アバターが1体のみ／いない」という状態を表示します。
- スクリーンショットの更新に合わせて右側のプレビューも更新し、古い画像が表示されたままになる問題を修正しました。
- 小さいウィンドウでも、ボタンや設定項目を確認しやすいレイアウトに改善しました。
- 絞り込みで選択中のカードが非表示になった場合は、右側の詳細もクリアし、操作対象を取り違えないようにしました。

**翻訳の改善**

- 日本語と英語の一部のボタン名を短くし、文字が切れにくくしました。
- 削除確認メッセージの未翻訳部分を補い、中国語と日本語が混在しないようにしました。

## *ver0.4 2026.11.13*

**不具合修正・画面表示の改善**

- データの読み込みに失敗した場合は元のファイルを保持し、関連する保存・撮影処理を停止するようにしました。
- 一部の旧シーン記録が移行時に失われる問題を修正しました。
- 複数のプロジェクト間でスクリーンショットの登録が混ざる問題を修正しました。
- タグの保存に失敗した場合の復元処理を改善し、画像削除時にはほかの記録で使われている画像を保護するようにしました。
- 一括更新で Unity の自動更新設定が変更されなくなりました。
- 並べ替えの表記とボタンのツールチップを見直し、中国語・日本語・英語の翻訳を調整しました。
