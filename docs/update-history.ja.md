# 更新履歴

## [0.02] - 2025.6.28

- パスと GUID の両方でエラーを確認し、互いの情報から修正できるようになりました。シーンが見つからなくなる問題を軽減しました。
- 起動と読み込みを高速化し、更新時に進捗バーを表示するようにしました。
- TagManagementWindow の UI レイアウトを改善しました。

## [0.03] - 2025.7.19

- スクリーンショットの日時で並べ替える機能を追加しました。

## [0.04] - 2025.8.23

- ダブルクリックでシーンを開けるようになりました。
- サムネイルを事前に選択しなくても、その上で右クリックメニューを開けるようになりました。
- Unity の Project ウィンドウと OS のファイルブラウザーで、ファイルの場所を表示する機能を追加しました。
- 撮影した画像がすぐに表示されない問題を修正しました。
- GUI の更新の遅れとエラーを修正しました。
- タグの背景色に合わせて、文字色を黒または白に自動で切り替えるようにしました。
- PNG/JPEG の切り替えと画質設定に対応し、保存時に同名の古い画像を削除するようにしました。
  - `Screenshot Settings...` ウィンドウを追加しました。
  - メニューを `Tools/CYN-lab/AvatarSceneBrowser/` に統一しました。
- イベントバスを導入し、ウィンドウ間の連携を改善しました。

## [0.1] - 2025.10

BOOTH で正式に公開しました。

## [0.11] - 2025.11.14

操作説明を追加しました。

## [0.2] - 2026.1

**1つのシーン内で複数の VRChat アバターを管理する機能**

- 同じシーン内のアバターごとに、スクリーンショットと設定を保存できるようになりました。
- 設定のサムネイルをダブルクリックするか、設定一覧の ▶ をクリックすると、アバターの表示・非表示を復元できます。
- ギャラリーで選択した画像には、Avatar 設定なら緑色、通常のシーン画像なら青色の枠を表示します。
- 右側の詳細パネルに、1体のアバターの設定か、複数のアバターの組み合わせかを表示します。
- Avatar 設定ごとにタグを付けられるようになりました。

## [0.21] - 2026.1.23

- Unity のバージョンによって UI の枠が真っ黒に表示される問題を修正しました。

## [0.22] - 2026.3.1

- シーン内のアバターが複数から1体になった際、古い複数アバターの画像に赤い警告アイコンを表示するようにしました。
- 現在開いているシーンで、画像が参照するアバターが削除されていた場合に、サムネイルに警告を表示するようにしました。
- シーンファイルの欠落と Avatar データの異常を分け、それぞれの件数をタイトルバーに表示するようにしました。

## [0.23] - 2026.3.20

- プラグイン名を `AvatarSceneBrowser` から `VRCAvatarSceneBrowser` に変更しました。
- メニューパスを `Tools/CYN-lab/VRCAvatarSceneBrowser/` に統一しました。
- 撮影ボタンからウィンドウを開いたときに、タイトルが `MainWindow` になる問題を修正しました。
