# 快速开始

---

## 第一步：截图

先打开要记录的场景，并保存为 `.unity` 文件。调整 Scene 视图，让想拍摄的内容出现在画面中；截图使用的是 Scene 视图的相机。

导入插件后，在 Scene 窗口的工具栏中找到截图和打开浏览器两个按钮。

![工具栏截图按钮](img/toolbar01.png)
![工具栏截图按钮](img/toolbar02.png)

点击截图按钮，为当前场景保存缩略图：

![截图按钮（亮色主题）](img/gui_Screenshot_light.png){ width="80" }

也可以从菜单打开主窗口：

`Tools → CYN-lab → VRCAvatarSceneBrowser → Main Window`

然后点击顶部的 **刷新当前打开的Scene截图**。

![刷新当前打开的场景截图](img/刷新当前打开的场景截图.png)

---

## 第二步：查看截图库

点击工具栏的浏览器按钮，或通过上面的菜单打开主窗口。保存的截图会显示在中间的画廊中；第一次使用时，需要先拍一张截图。

可以调整缩略图大小，按名称、创建时间或修改时间排序，也可以通过左侧的搜索和标签筛选查找场景。

[→ 主窗口详情](main-window.md)

---

## 第三步：打开 Scene

普通场景截图有三种打开方式：

1. **双击缩略图**。
2. **右键缩略图 → 打开场景**。
3. **选中缩略图 → 点击右侧“打开此场景”**。

如果双击的是 Avatar 配置截图，会打开场景并加载对应的 Avatar 显示状态。只想打开场景时，使用右键菜单中的 **仅打开场景**，或右侧的 **打开此场景** 按钮。

切换场景时，如果当前场景有未保存的修改，Unity 会提示是否保存。

---

## 第四步：添加标签

选中缩略图，在右侧的标签区域选择已有标签并点击 **添加**；也可以输入新标签名称、选择颜色，再点击 **创建新标签**，直接加到当前选中项上。

普通场景截图使用场景标签，Avatar 配置截图使用各自的配置标签。给一个配置添加标签，不会同时加到同场景的其他配置上。

标签的编辑和管理请参见 [标签管理](tag-manager.md)。

---

## 多 Avatar 场景的使用

当前版本会统计场景里的 VRChat Avatar，包括未激活的对象。场景中有 **至少两个 Avatar** 时，截图会记录 Avatar 配置；只有一个或没有 Avatar 时，使用普通场景截图。

为场景中的不同 Avatar 保存截图：

1. 在 Hierarchy 中，用 Avatar 根对象的激活开关打开要拍摄的 Avatar，关闭其他 Avatar。这里指 Inspector 顶部的勾选框，不是 Hierarchy 的眼睛图标。若 Avatar 放在其他对象下面，也要保持父对象激活；加载配置不会自动打开父对象。
2. 调整 Scene 视图，点击工具栏截图按钮。
3. 对其他 Avatar 重复操作，画廊中会出现各自的配置截图。

也可以同时激活多个 Avatar，确认提示后把它们保存为一个组合。若所有 Avatar 都关闭，确认后会保存“无Avatar”配置。

!!! info "再次截图"
    同一组 Avatar 的激活状态再次截图时，会更新已有配置的图片，不会重复新增配置。要更新某个配置，先加载它，再点击工具栏截图按钮或主窗口顶部的“刷新当前打开的Scene截图”。

恢复 Avatar 状态有三种方式：

- 双击配置缩略图。
- 右键配置缩略图，选择 **打开场景并加载配置**。
- 选中缩略图，在右侧 **Avatar 配置** 区域点击对应行的 **▶**。

配置保存的是 Avatar 根对象的激活状态，不会还原服装、材质、姿势或 Scene 视角。加载后如果希望保留当前状态，需要保存 Unity 场景。

!!! info "注意"
    Avatar 配置功能需要 VRChat SDK（VRCSDK3）。未安装 SDK 时仍可截图，但不会保存 Avatar 配置。

## Unity 菜单

```text
Tools
└── CYN-lab
    └── VRCAvatarSceneBrowser
        ├── Main Window              # 主窗口
        ├── GUID Batch Update Tool   # GUID 批量更新工具
        └── Screenshot Settings...   # 截图格式/质量设置
```

### Main Window（主窗口）

浏览截图、打开场景、筛选标签和管理 Avatar 配置。

### GUID Batch Update Tool（GUID 批量更新工具）

检查场景记录的路径与 GUID，在仍能找到原场景文件时修复关联。[→ 详情](guid-batch-update-tool.md)

### Screenshot Settings...（截图设置）

选择 PNG 或 JPEG。JPEG 质量可在 1～100 之间调整，默认值为 80；PNG 不使用此质量设置。点击 **Save** 保存，**Close** 关闭而不保存。本设置只影响之后拍摄的图片，不会批量转换已有截图。
