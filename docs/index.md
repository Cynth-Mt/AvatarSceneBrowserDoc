## 环境与语言

插件界面支持中文、日文和英文，可在主窗口顶部切换。

- **Unity 2022.3.22f1 LTS**
- Avatar 识别和配置功能需要 **VRChat SDK（VRCSDK3）**；未安装 SDK 时仍可使用普通场景截图。

## 导入 UnityPackage

从 [Booth 页面](https://cyn-m.booth.pm/items/5548166) 下载最新的 `.unitypackage` 文件

1. 在 Unity 编辑器中，选择 `Assets > Import Package > Custom Package...`
2. 选择下载的 `.unitypackage` 文件
3. 在导入窗口中确认所有文件都被选中，然后点击 `Import`

或者直接双击打开 `.unitypackage`
