# GUID 批量更新工具  GUID管理

## 使用场景

当浏览器记录的场景路径或 GUID 与项目里的文件不一致时，可以用这个工具检查和修复。

- 场景移动或重命名后，检查记录的路径是否需要更新。
- 导入旧数据或迁移项目后，检查缺失或不一致的 GUID。
- 主窗口提示场景文件缺失时，确认是否仍能找到原文件。

-----

![GUID工具](img/GUIDtool.png)

## 打开工具

- 在主窗口顶部点击 **GUID工具**。
- 或使用菜单：`Tools → CYN-lab → VRCAvatarSceneBrowser → GUID Batch Update Tool`。

## 界面与功能

### 按钮与颜色

![GUID工具](img/GUIDtool2.png)

- ① **检查数据**：重新读取场景记录，检查路径、GUID 和文件是否对应。
- ② **修复所有问题**：确认后批量修复能够找回文件的记录。
- ③ **仅显示问题项**：隐藏正常记录，方便查看需要处理的条目。

也可以在目标行点击 **修复**，只处理这一条记录。

| 状态 | 颜色 | 说明 | 处理 |
|------|------|------|------|
| 正常 | 绿色 | 路径与 GUID 对应，文件存在 | 无需处理 |
| 路径需更新／路径不匹配 | 黄色 | GUID 指向的文件位置与记录不同 | 检查实际路径后修复 |
| 无 GUID／GUID 需更新 | 黄色 | 场景文件存在，但记录的 GUID 缺失或不一致 | 修复 GUID |
| 文件缺失 | 红色 | 通过记录的路径和 GUID 都找不到场景 | 检查原文件或备份 |

> 场景文件缺失时，主窗口的缩略图也会显示错误图标。
>
> ![GUID工具](img/GUIDtool3.png)

#### 数据列说明

| 列 | 内容 |
|------|------|
| 记录路径 | 浏览器保存的 Scene 路径 |
| 实际路径 | 通过 GUID 查到的路径 |
| 状态 | 当前检查结果 |
| 当前 GUID | 浏览器记录中的 GUID |
| 实际 GUID | 当前场景文件的 GUID |
| 操作 | 对可修复条目执行修复 |

## 注意事项

- 修复会修改插件的 `Data/scenes_data.json`，操作前可先备份该文件。
- 黄色表示记录有不一致，并不一定影响打开场景；请先核对实际路径。
- 如果原路径和 GUID 都找不到文件，工具无法自动恢复被删除的场景。
- 本工具只处理场景记录，不修复 Avatar 配置中丢失的对象，也不恢复截图图片。
