# VRC Avatar Scene Browser

Organize Unity scenes with screenshots and tags, then open them with a double-click. For scenes with multiple avatars, save and restore different combinations of active avatars.

Documented plugin version: **v0.23** · [Changelog](update-history.md)

## Environment and languages

The plugin supports Chinese, Japanese, and English. Switch languages at the top of the main window.

- **Unity 2022.3.22f1 LTS**
- Avatar detection and configurations require **VRChat SDK (VRCSDK3)**. Standard scene screenshots also work without the SDK.

## Importing the UnityPackage

Download the latest `.unitypackage` file from the [Booth page](https://cyn-m.booth.pm/items/5548166).

1. In Unity, choose `Assets > Import Package > Custom Package...`.
2. Select the downloaded `.unitypackage` file.
3. Make sure all files are selected, then click `Import`.

You can also double-click the `.unitypackage` file to import it.
