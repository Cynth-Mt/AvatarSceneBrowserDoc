# VRC Avatar Scene Browser

VRC Avatar Scene Browser is a Unity Editor extension for VRChat users.

Take a screenshot of a scene, then use the browser to find it by its thumbnail, add tags, and open it with a double-click.

If you keep different avatars or outfits in separate Unity scenes, you can use the browser to organize them. For scenes containing multiple avatars, you can also save screenshots of different combinations of active avatars and restore those combinations later.

**The version currently shown in the main window is v0.23.** The plugin interface supports Chinese, Japanese, and English. You can switch languages at the top of the main window.

Booth: [Get the plugin](https://cyn-m.booth.pm/items/5548166)

Development environment

- **Unity 2022.3.22f1 LTS**
- Avatar detection and configurations require **VRChat SDK (VRCSDK3)**. Standard scene screenshots also work without the SDK.

## Importing the UnityPackage

Download the latest `.unitypackage` file from the [Booth page](https://cyn-m.booth.pm/items/5548166).

1. In Unity, choose `Assets > Import Package > Custom Package...`.
2. Select the downloaded `.unitypackage` file.
3. Make sure all files are selected, then click `Import`.

You can also double-click the `.unitypackage` file to import it.
