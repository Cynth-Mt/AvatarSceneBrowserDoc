# メインウィンドウ

## タイトルバー

![タイトルバー](img/场景浏览-全部场景.png)

上部では UI の言語を中国語・日本語・英語から選べます。各ボタンの機能は次のとおりです。

- **現在のシーンのSSを更新**：現在の Scene ビューを撮影します。シーン内にアバターが2体以上いる場合は、現在の Avatar 設定を保存します。
- **全SSを更新（時間がかかる）**：ライブラリのシーンを順番に開き、通常のシーンスクリーンショットを撮影します。進捗が表示され、途中でキャンセルできます。
- **GUIDツール**：シーンのパスと GUID の関連付けを確認・修正します。
- **SS設定**：PNG/JPEG と JPEG の品質を選びます。

!!! info "Avatar 設定の画像を更新するには"
    「全SSを更新」では、Avatar 設定を1つずつ読み込んで撮り直すことはできません。対象の設定を読み込んでから、ツールバーの撮影ボタン、または「現在のシーンのSSを更新」を使ってください。一括更新すると、既存の設定が古いと判定され、警告が出ることがあります。

## 中央エリア（スクリーンショットギャラリー）

保存したシーンの画像と Avatar 設定の画像が並びます。同じシーンに複数の設定があれば、それぞれ別のサムネイルとして表示されます。

**サムネイルは2種類あります。**

- **青色の枠**：通常のシーンスクリーンショットです。主に、アバターがいないシーンや1体だけのシーンで使います。
- **緑色の枠**：Avatar 設定のスクリーンショットです。複数のアバターがいるシーンで、アクティブ状態の組み合わせを記録します。

① 並び順とサムネイルの大きさ

スライダーでサムネイルの大きさを調整できます。並び順は名前順のほか、作成日時・更新日時の新しい順と古い順を選べます。

!!! info "日時による並べ替え"
    プラグインが保存した日時を使います。ディスク上の Unity シーンファイルの更新日時ではありません。設定の画像を撮り直すと、作成日時を残したまま更新日時が変わります。

② スクリーンショットの表示エリア

サムネイルをクリックすると詳細を表示します。通常の画像をダブルクリックするとシーンを開き、Avatar 設定の画像ならシーンを開いて設定も読み込みます。

左側の検索欄はシーンのパスを対象にします。シーン名やフォルダー名で検索でき、Avatar 設定の名前は検索対象に含まれません。タグによる絞り込みもできます。複数のタグを選んだ場合は、すべてのタグに一致する項目を表示します。シーンタグが一致すればそのシーンの設定を表示し、設定自体のタグでも絞り込めます。**クリア** をクリックするとタグの絞り込みを解除します。

③ 「シーンライブラリ」の右側にある状態表示

- 1人の人型エラーアイコンの横の数字：シーンファイルが見つからない記録の数です。
- 複数人の人型エラーアイコンの横の数字：現在のギャラリーで、古い設定やアバターの欠落に関する警告が出ている設定の数です。アバターが見つかるかどうかの確認は、現在アクティブなシーンに対してのみ行います。
- これらの問題が検出されていなければ、緑色の状態アイコンを表示します。

### 個別サムネイル

![シーン閲覧-単独](img/场景浏览-单独.png)

① 上部にはシーン名を表示します。Avatar 設定の場合はアバター名、組み合わせの場合は名前を `+` でつないで表示します。

② 下部には、そのシーンまたは設定に付けたタグを表示します。

③ エラーアイコンは、シーンファイルが見つからない、設定が古いと判定された、または設定が参照するアバターが見つからないことを示します。シーンのパスは [GUID ツール](guid-batch-update-tool.md)で確認できます。アバターの問題はシーンを開いて確認してください。

## 右クリックメニュー

通常のシーンサムネイルを右クリックすると、次の操作ができます。

- シーンを開く。
- スクリーンショットを更新する。
- Unity の Project ウィンドウ、または OS のファイルブラウザーでシーンファイルの場所を表示する。
- そのシーンのタグをすべて外す。
- スクリーンショットデータを削除する。

Avatar 設定のサムネイルでは、開く操作が **シーンを開いて設定を読込** と **シーンのみを開く** に分かれています。タグのクリアと削除は、選択した設定が対象です。

!!! info "右クリックからの画像更新"
    現在、右クリックメニューの「スクリーンショット更新」は通常のシーンスクリーンショットを撮影します。選んだ Avatar 設定を先に復元する処理はありません。設定の画像を更新する場合は、このページ上部の手順を使ってください。

## 右側の詳細情報

サムネイルを選ぶと、右側にプレビュー、シーンの情報、タグ編集欄が表示されます。**シーンを開く** ボタンではシーンを開くだけで、Avatar 設定は読み込みません。

通常の画像を選ぶと **シーンタグ**、Avatar 設定を選ぶと **設定タグ** を編集できます。タグの横の **×** は、その項目からタグを外す操作です。タグ自体は削除しません。

### 小ボタン

![シーン詳細欄](img/场景浏览-详细栏.png)

① Unity の Project ウィンドウでシーンファイルを選択します。

② OS のファイルブラウザーでシーンファイルの場所を表示します。

③ 確認後、選択した項目のスクリーンショットデータを削除します。`.unity` ファイルは削除しません。

**シーンを開いてスクリーンショットを更新** も、右クリックの「スクリーンショット更新」と同じく、通常のシーンスクリーンショットを更新します。

!!! warning "削除されるデータ"
    通常の画像を削除すると、そのシーンのブラウザー上の記録も削除されます。Avatar 設定を削除すると、該当する設定と画像が削除されます。そのシーンの最後の設定だった場合は、以前に通常の画像を保存していても、シーンの記録も削除されます。削除操作は元に戻せません。

## Avatar設定パネル（複数Avatar機能）

シーンまたは設定を選ぶと、右側下部の **Avatar 設定** 欄に、そのシーンで保存した設定が並びます。設定がない場合は案内が表示されます。

- 各行が、保存したアバターのアクティブ状態の組み合わせです。
- ★ 緑色：アバターが1体だけアクティブな設定。
- ◆ オレンジ色：複数のアバターがアクティブな設定。
- アクティブなアバターがいない設定は灰色で表示されます。
- **▶**：シーンを開き、記録したアバターのアクティブ状態を復元します。
- **✕**：確認後、その設定を削除します。

!!! tip "設定の作成と更新"
    VRChat アバターが2体以上いるシーンで、各ルートオブジェクトのアクティブ状態を調整し、ツールバーの撮影ボタンをクリックします。新しい組み合わせなら設定を追加し、既存の組み合わせなら画像を更新します。設定を読み込んでも、衣装・マテリアル・撮影時の視点は復元されません。
