# 更新日志

## [0.02] - 2025.6.28

- 新增路径与GUID双重错误检查，支持路径和GUID互相修复，场景丢失问题大幅减少
- 启动和加载速度提升，刷新时有进度条提示
- 优化TagManagementWindow的UI布局

## [0.03] - 2025.7.19

- 截图排序功能，现在是依照截图的时间来排序

## [0.04] - 2025.8.23

- 双击直接打开场景
- 增强右键菜单，限定在缩略图上右键，无需先选中
- 新增文件定位：Unity项目窗口显示、系统文件浏览器显示
- 解决新截图无法实时显示的问题
- 修复GUI刷新延迟和错误
- 根据标签背景色自动选择黑/白文字
- 截图格式/质量设置：支持 PNG/JPEG 切换，保存时自动清理同名旧文件
  - 新增 `Screenshot Settings...` 设置窗口
  - 菜单统一：所有入口归于 `Tools/CYN-lab/AvatarSceneBrowser/`
- 引入事件总线，改善多个窗口之间的通信

## [0.1] - 2025.10
BOOTH 正式发布

## [0.11] - 2025.11.14
添加操作说明文档

## [0.2] - 2026.1

**一个场景内多个 VRC Avatar 的管理功能**

- 支持在同一场景中为不同的 Avatar 分别截图并保存配置
- 双击配置缩略图，或点击配置列表中的 ▶，可以恢复对应 Avatar 的显示/隐藏状态
- 画廊中选中的 Avatar 配置截图显示绿色边框，选中的普通场景截图显示蓝色边框
- 右侧详情面板显示配置类型（单Avatar配置 / 多Avatar组合）
- 支持为每个 Avatar 配置单独设置标签

## [0.21] - 2026.1.23

- 修复 UI 区域边框在不同 Unity 版本下显示为纯黑色的问题

## [0.22] - 2026.3.1

- 多Avatar数据状态警告：当场景从多Avatar变为单Avatar后，旧的多Avatar截图会显示红色警告图标
- Avatar缺失检测：当前加载场景中，如果 Avatar 截图引用的 Avatar 已被删除，缩略图显示警告图标
- 标题栏错误统计分离：场景文件丢失与 Avatar 数据异常分别独立计数和显示

## [0.23] - 2026.3.20

- 插件名称从 `AvatarSceneBrowser` 更名为 `VRCAvatarSceneBrowser`
- 菜单路径统一更新为 `Tools/CYN-lab/VRCAvatarSceneBrowser/`
- 修复截图按钮打开窗口时标题显示为 `MainWindow` 的问题

## *ver0.3 2026.11.2*
**Bug 修复**

- 同名场景或 Avatar 的配置截图不再互相覆盖，重新截图也会保留原来的配置和标签。
- Avatar 配置截图保存失败时，会保留旧图及其关联，并显示错误提示。
- 删除单张截图或配置时，不会误删其他配置共用的图片；删除失败会恢复原有数据。
- 修复使用符号链接的工程中，图片删除后仍有残留的问题。
- 取消切换场景后，不再继续更新截图。
- 标签改名后，相关 Avatar 配置里的名称也会一起更新，标签颜色保持不变。
- 标签保存失败时，会恢复原有数据并显示错误提示。
- 标签使用次数现在也会统计 Avatar 配置中的使用情况。

**界面调整**

- 更新角色状态说明，更清楚地区分多角色场景中显示的是单个还是多个角色。普通截图需打开对应场景后，才会显示“只有一个／没有 VRC 角色模型”。
- 更新截图后，右侧预览会跟着刷新，避免显示错图。
- 改善小窗口下的排版，让按钮和设置更容易看全。
- 筛选后，如果选中的卡片被隐藏，右侧详情也会清空，避免弄错操作对象。

**翻译调整**

- 缩短部分日文、英文按钮文字，减少文字显示不全的情况。
- 补齐删除确认提示的翻译，避免中日文混用。

## *ver0.4 2026.11.13*

**Bug 修复与界面调整**

- 数据读取失败时保留原文件，停止相关保存和截图操作。
- 修复部分旧场景记录在迁移时丢失的问题。
- 修复多个工程之间截图登记互相干扰的问题。
- 完善标签保存失败后的恢复，并在删除截图时保护其他记录仍在使用的图片。
- 批量刷新不再改变 Unity 的自动刷新设置。
- 优化排序文字和按钮提示，同步调整中日英翻译。
